# Magnet Metrology Course

Written lecture material for a 35 class self-directed course on permanent magnet
metrology. The end state is a working bench that maps and images permanent
magnet fields and tracks them over years.

This directory is self contained and has nothing to do with the Alarm Log Pareto
tool in the rest of this repository. They share a repository and nothing else.
The root `requirements.txt` belongs to the alarm tool. This course has its own,
here.

## Where to start

| File | What it is |
|---|---|
| `CLAUDE.md` | Standing rules for every session. Read first. |
| `KICKOFF.md` | The session zero prompt. Already run, partially. See `PROGRESS.md`. |
| `BUILD_PROMPTS.md` | Per session prompts from session two onward. |
| `PROGRESS.md` | Status of all 35 classes, and what is currently blocked. |
| `CHANGES.md` | Proposed changes to `CLAUDE.md` and the syllabus. Never applied silently. |
| `syllabus/` | The fixed HTML syllabus and the research checklist. |
| `library/` | Source index, verification log, reading queue, cached PDFs. |
| `shared/` | Notation, glossary, and the reference part. Not written yet. |
| `classes/` | One directory per class. Empty. |
| `reviews/` | Unit reviews and the adversarial pass. Empty. |
