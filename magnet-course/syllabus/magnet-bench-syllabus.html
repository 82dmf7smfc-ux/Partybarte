How this course is built

Each class is 90 minutes by default and follows the same shape: a short framing, a source read with a specific question to answer, a worked calculation or hands-on step, then a written artifact. The artifact is the point. If a class does not leave a file, a sketch, or a number behind, it did not happen.

The order is a suggestion, not a rule. Theory is placed just before the class that needs it, so reading straight through means nothing arrives cold. Jump ahead whenever a real problem pulls you there. The checkpoint at the end of each unit tells you what should be working by then and what tends to go wrong if it is not. Treat it as a warning label, not a lock.

The source list is dominated by the accelerator magnet community and by vendor technical staff. That is deliberate. Both publish measurement practice openly, in far more detail than the standards bodies do, and the physics is identical to yours. Paid standards appear only where they are genuinely the authority, and each one is paired with a free document that covers the same ground.
