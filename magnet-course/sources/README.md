# This directory is not the source library

`CLAUDE.md` lists both `/sources/` and `/library/` as holding `sources.json` and
`verified.log`. Only one can be the single source of truth.

**The library lives in `/library/`.** See `library/sources.json`,
`library/verified.log`, `library/queue.md`, `library/export.bib`,
`library/pdf/`, and `library/notes/`.

This directory exists only so that someone following the layout block in
`CLAUDE.md` lands here and is redirected rather than creating a second,
competing copy. The conflict is written up in `CHANGES.md`, item 1.
