Alarm Log Pareto

Import one or more elog files for a tool. See the most frequent faults and the biggest downtime. Runs fully offline in your browser.

1. Import elog files

Select one or more CSV or delimited text files from the same tool. Nothing leaves your computer. No internet is used.

2. Tell the tool which column is which

The tool guessed the columns from their names. Fix any that are wrong. Only Timestamp and Fault code are required.

3. Settings

The window ends at the latest timestamp found in your files, not today's date.

Leave both time boxes empty to cover all hours. The range keeps the "from" minute and stops just before the "to" minute, so two shifts add up to one day with nothing counted twice. A "from" later than the "to" wraps past midnight, so 22:00 to 06:00 is the night shift. Alarms are picked by the time they started; an alarm that runs past the end of the range still counts its whole duration.
