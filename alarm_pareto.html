Alarm Log Pareto

Import one or more elog files for a tool. See the most frequent faults and the biggest downtime. Runs fully offline in your browser.

1. Import elog files

Select one or more CSV or delimited text files from the same tool. Nothing leaves your computer. No internet is used.

2. Point at your data and label the columns

Data is read from that row down until the first blank line. Rows older than the window are dropped later. The same start row is used for every file you import.

Set what each column holds. Only Timestamp and Fault code are required. Pick "Other" to name a column you want to keep in view but not analyze.

Tag the duration column as "Duration" in the table above.
Tag the state column as "Alarm state" in the table above.

3. Settings

The window ends at the latest timestamp found in your files, not today's date.
