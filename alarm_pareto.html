Alarm Log Pareto

Import one or more elog files for a tool. See the most frequent faults and the biggest downtime. Runs fully offline in your browser.

1. Import elog files

Select one or more log files from the same tool. Comma or tab files and P5000 Etch elogs both work. Nothing leaves your computer. No internet is used.

2. Point at your data and label the columns

Data is read from that row down until the first blank line. Rows older than the window are dropped later. The same start row is used for every file you import.

"Auto-map" guesses each column from its values. Fix any that are wrong. You need a Timestamp (or a Date), plus a Message ID. Tag more than one column as Description to join split message text. Pick "Other" to keep a column in view but not analyze.

The tool reads the chamber name from the Description text, then pairs a "down" message with the next "online" message for that chamber. Downtime is estimated, not measured. The lists below are editable because vendors word these differently. One phrase or name per line. Matching ignores case and extra spaces.

Group similar messages under one name for the Category Pareto. Built-in rules run automatically. Add your own here, one per line, as pattern => Label (a case-insensitive regular expression on the message text) or id:494,495 => Label (an exact match on the Event Number, which is more reliable when a message's text varies). Your rules run first. Saved in this browser.

When a row has no chamber tag, the tool looks for one of these names in the message text and uses it as the Module. One name per line, matched without case. Helps events like "front panel" or "wafer handler" land on a module. Saved in this browser.

3. Settings

The window ends at the latest timestamp found in your files, not today's date.
