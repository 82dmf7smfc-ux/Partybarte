# The package list for the whole repository.

# Each project pins the packages it actually needs, in its own folder. This file
# just gathers them, so one install from the repository root gives you an
# environment that can run every project and every test.
#
# It works this way for two reasons. A download package should only ask a person
# to approve the packages that tool really imports. And when you ask IT to
# approve wheels for one tool, you want to hand them a short list, not the whole
# repository.
#
# Install from local wheels like this (offline):
#   pip install --no-index --find-links C:\path\to\wheels -r requirements.txt
#
# pip reads the paths below relative to this file, so run it from the root.
#
